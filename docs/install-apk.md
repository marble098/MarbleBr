# نصب APK رسمی MarbleBr

1. از بخش [GitHub Releases](https://github.com/marble098/MarbleBr/releases) یکی از فایل‌های `.apk` نسخهٔ رسمی را بگیرید. فایل‌های **Source code** و خروجی‌های **Actions / test-only** برای نصب یا ارتقای نسخهٔ رسمی نیستند.
2. اگر معماری را نمی‌دانید، **`universal`** را انتخاب کنید. این فایل بزرگ‌تر است ولی برای تمام معماری‌های پشتیبانی‌شده کافی است. فقط **یک** APK لازم است.

| پسوند | مناسب برای |
| --- | --- |
| `arm64-v8a.apk` | بیشتر گوشی‌ها و تبلت‌های امروزی ARM ۶۴ بیتی، از جمله دستگاه‌های فقط ۶۴ بیتی |
| `armeabi-v7a.apk` | دستگاه‌های سازگار با ARM ۳۲ بیتی |
| `x86_64.apk` | اندروید با پردازندهٔ Intel/AMD ۶۴ بیتی، از جمله بعضی شبیه‌سازها |
| `universal.apk` | هر سه مورد بالا |

حداقل نسخه **Android 8.0 (API 26)** است. اینتل ۳۲ بیتی (`x86` بدون `_64`) در GeckoView فعلی پشتیبانی نمی‌شود؛ APKهای `x86` قدیمی را نصب نکنید. در شبیه‌ساز روی کامپیوتر ۶۴ بیتی، یک تصویر سیستم `x86_64` انتخاب کنید. با ADB می‌توانید معماری اندروید را از `adb shell getprop ro.product.cpu.abilist` بخوانید؛ صرفاً ۶۴ بیتی بودن پردازنده کافی نیست.

## اگر Android گفت «برنامه نصب نشد»

- **فایل ناقص، تغییرکرده یا بستهٔ اشتباه:** دوباره از GitHub Releases دانلود کنید. مقدار `sha256sum نام-فایل.apk` (یا `Get-FileHash -Algorithm SHA256 نام-فایل.apk` در PowerShell) باید با سطر همان فایل در `SHA256SUMS` همان انتشار یکی باشد. فایل را بازبسته‌بندی یا دوباره امضا نکنید.
- **نسخهٔ پایین‌تر:** نسخه‌ای هم‌سطح یا جدیدتر از نسخهٔ نصب‌شده بگیرید. اگر پیش‌انتشار جدیدتری نصب کرده‌اید، ممکن است نسخهٔ پایدار فعلی قابل نصب روی آن نباشد؛ منتظر نسخهٔ هم‌سطح یا جدیدتر بمانید.
- **امضای متفاوت:** یک APK دست‌کاری‌شده، خروجی آزمایشی یا نسخهٔ محلی نمی‌تواند با APK رسمی جایگزین شود. وجود نسخه در پروفایل کاری یا حساب دیگری روی دستگاه را هم بررسی کنید. ابتدا تا حد ممکن داده‌های مهم را ذخیره کنید و فقط اگر راه دیگری نبود نسخهٔ ناسازگار را حذف کنید. **حذف برنامه می‌تواند نشست‌ها، گذرواژه‌های ذخیره‌شده و سایر داده‌های محلی را پاک کند**؛ حذف برنامه برای ارتقای نسخهٔ رسمی لازم نیست.
- **فضا یا مجوز نصب:** پس از دانلود، نصب به فضای آزاد اضافه در حافظهٔ داخلی نیاز دارد. تنظیم «نصب برنامه‌های ناشناس» را برای همان مرورگر یا فایل‌منیجر بررسی کنید. سیاست پروفایل کاری/والدین، محدودیت سازنده یا هشدار Play Protect ممکن است نصب را مسدود کند؛ محدودیت مدیر دستگاه یا هشدار امنیتی را دور نزنید.
- **علت دقیق:** در صورت امکان `adb install -r نام-فایل.apk` را اجرا کنید. `NO_MATCHING_ABIS` یعنی معماری ناسازگار، `OLDER_SDK` یعنی اندروید قدیمی، `UPDATE_INCOMPATIBLE` یعنی معمولاً تعارض امضا، و `VERSION_DOWNGRADE` یعنی نسخهٔ نصب‌شده جدیدتر است. برای گزارش مشکل مدل دستگاه، نسخهٔ اندروید، نام کامل APK و کد خطا را بفرستید؛ نیازی به ارسال اطلاعات شخصی یا محتوای نشست‌ها نیست.
